# Starrygpu

Starrygpu is the Starry wrapper for D3D11-level GPUs (compute shaders, indirect rendering). This package has no dependencies on the rest of Starry, and so can be taken out for your own projects.

## Backends

| Graphics API | Status      |
| ------------ | ----------- |
| OpenGL Core  | Stable      |
| Vulkan       | Planned     |
| Direct3D 11  | Planned     |
| Direct3D 12  | Unlikely    |
| Metal        | Unlikely    |
| OpenGL ES    | Unsupported |
