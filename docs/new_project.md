Step 1: acquire starry

Step 2: make a new file called `app.json` next to `starry.exe`:

```json
{
    "name": "massive game",
    "main": "main.lua"
}
```

Step 3: make a new file called `main.lua`:

```lua

	print("Gsjhjsshs")
end
```
